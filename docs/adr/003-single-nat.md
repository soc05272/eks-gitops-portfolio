# ADR-003: NAT Gateway를 단일 AZ 1개로 구성한 이유

- 상태: 승인
- 날짜: 2026-07-24

## 배경

프라이빗 서브넷의 EKS 노드가 외부(ECR, GitHub 등)로 나가려면 NAT가 필요.
NAT Gateway는 시간당 과금(월 약 $40/개)으로 이 프로젝트의 주요 고정비용이다.

## 선택지

1. **AZ별 NAT Gateway (2개)** — AZ 장애 시에도 아웃바운드 유지. 월 약 $80.
2. **단일 NAT Gateway (1개)** — 비용 절반. NAT가 있는 AZ 장애 시 다른 AZ 노드의 아웃바운드가 끊긴다.
3. **NAT Instance (t4g.nano 자체 운영)** — 월 $3~4로 가장 저렴하나 직접 관리 필요, 대역폭 제한.

## 결정

**단일 NAT Gateway 선택.**

- 포트폴리오 환경에서 AZ 장애까지 대비하는 것은 비용 대비 과잉
- NAT Instance는 더 저렴하지만, 관리 포인트가 늘어나 "과하지 않게" 원칙에 어긋남
- 프로덕션이라면 AZ별 NAT가 표준임을 인지하고 문서화

## 트레이드오프

- 단일 장애점(SPOF) 존재 → 허용 (개발/포트폴리오 환경)
